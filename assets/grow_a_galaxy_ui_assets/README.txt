Grow a Galaxy UI Asset Pack
===========================

Contents:
- sheet_1_core_kit/: 36 individually cropped transparent PNG assets.
- sheet_2_extra_kit/: 26 individually cropped transparent PNG assets.
- asset_manifest.csv: semantic filename/category/description and output dimensions.
- *_labeled_index.png: visual index sheets for quickly identifying assets.

Naming convention:
NN_descriptive_asset_name.png

The original generated artwork was preserved; the operation only crops/isolate assets and clears nearly invisible alpha noise at the crop edges.
