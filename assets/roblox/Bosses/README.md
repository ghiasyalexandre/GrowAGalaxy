# Boss models

Rojo syncs this folder to `ServerStorage/Assets/Bosses` (server only). `RaidBuilder` uses
`DeathStar.rbxm` (a MeshPart named DeathStar) as the raid boss, resized to
`Config.Raids.BOSS_SIZE`. Without the file a grey sphere stands in. See
[stage 19](../../../docs/stage-19-iss-raids.md).
