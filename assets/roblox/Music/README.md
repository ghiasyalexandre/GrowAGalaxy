# Music

Rojo syncs this folder to `ReplicatedStorage/Assets/Music`. `AudioController` loops
`SpaceMusic.rbxm` (a Sound) as the game music and crossfades to `SpaceDisco.rbxm` during Death
Star raids. Each track keeps its own volume; the Settings panel scales all music. See
[stage 21](../../../docs/stage-21-hangar-paint-settings.md).
